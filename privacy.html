Privacy policy

Last updated 21 October 2026

This is a personal website. It has no accounts, no forms, no comments and no newsletter. It sets no cookies and runs no analytics or tracking scripts.

What other services see

Loading a page sends a normal web request, which includes your IP address and browser details, to these services:

  • GitHub Pages, which hosts the site. GitHub may log visits for security. See the GitHub General Privacy Statement.
  • Google Fonts, which serves the fonts. See the Google Fonts privacy FAQ.
  • cdnjs (Cloudflare), which serves the three.js library used for the 3D chart. See the Cloudflare privacy policy.
  • GitHub (raw.githubusercontent.com), which serves the research figures.

I do not receive or store any of this data.
